# 📱 Motivus Reset — Instagram Studio

Lokální webová aplikace pro tvorbu příspěvků pro Instagram profil **@motivus.reset**.

## Jak spustit

1. Otevři soubor `app/index.html` v prohlížeči (Chrome nebo Firefox)
2. Vyber šablonu, zvol barvu, vyplň text
3. Klikni **Stáhnout PNG** → soubor se uloží do Stažených souborů
4. Klikni **Kopírovat popisek** → zkopíruje se caption s hashtagy
5. Otevři Instagram na telefonu a vytvoř nový příspěvek

## Šablony

| Šablona | Použití |
|---------|---------|
| 💬 Citát | Silná myšlenka nebo citát na barevném pozadí |
| 📚 Edukace | Vzdělávací příspěvek s nadpisem a body |
| 🗓️ Workshop | Oznámení workshopu nebo akce |
| ✅ Tipy | Praktická technika nebo tipy krok za krokem |
| 🌿 Osobní | Foto s textem – osobní příspěvek |

## Struktura

```
app/          → webová aplikace (index.html, style.css, app.js)
exports/      → sem patří stažené PNG soubory
obsah/        → zásobník textů a hashtagů
templates/    → připravené texty pro různé typy příspěvků
```
